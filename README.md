# InputRelay-Godot

**Improved input manager for Godot 4.7+ focused on action context design philosophy**

[![Godot](https://img.shields.io/badge/Godot-4.7%2B-478cbf?logo=godot-engine&logoColor=white)](https://godotengine.org/download)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Status](https://img.shields.io/badge/status-WIP-orange)](#install)

## Features

- **Contextual Input Actions** - Dynamically shift input actions based on gameplay context
- **SteamInput Support** - Be ready to launch without extra setup
- **Local Multiplayer** - No extra hassle
- **Dynamic Glyphs** - Display input glyphs dynamically for the device currently in use
- **Input Rebinding** - No extra work or rebind management
- **Gyro and Light Support** - Take full advantage of modern gamepad features

## Install
 
After adding the latest [Release](../../releases/latest) to your project, enable the addon in your project settings.
 
> **Note:** InputRelay is still in early development (WIP). APIs and features may change before a stable release.
